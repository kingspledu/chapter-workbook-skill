# Image-led workbook design

Use this mode when the design reference is richly illustrated or the user explicitly requests page-by-page image generation. Preserve the agreed activities and wording; do not change a cloze into a word search merely because the design sample contains one.

1. Render representative reference pages at readable resolution. Record visual decisions: illustration scale and occupied area, watercolor/paint texture, line style, character identities, header geometry, ribbons, cloud frames, borders, writing spaces and typography. A palette alone is not a design match.
2. If requested, generate ONE exact 4×4 atlas of 16 coordinated design elements. Specify all 16 cells, fixed identities and isolated assets with inset margins. Ask the image model for true transparency when needed. Inspect every cell and split using `scripts/split_atlas.py`; the script performs grid slicing only. Keep the original sheet.
3. Use the reference and atlas as style/character inputs for a SEPARATE image-model generation of every page. One repeated page background does not satisfy page-by-page generation. Specify A4 portrait, flat document view, no perspective, no text, and exact reserved content zones using normalized coordinates. Give each page an appropriate unique scene and illustration placement. Preserve the same characters and ornamental language.
4. Typeset the exact reviewed exercise text on top of each painting. Keep English and Korean text editable. Generate blank art rather than trusting dense model-generated bilingual text. Create numbers, answer lines, checkboxes and exercise data from the reviewed chapter model. Apply the atlas elements where useful, without duplicating an existing icon or leaving conspicuous white squares over painted backgrounds.
5. Inspect each generated page BEFORE placing text. Models can move panels or invent an extra word-bank box; adapt the text geometry to the actual panel or regenerate that page. Percentage instructions are not proof of alignment. Preserve comfortable child-sized text and useful handwriting space. Avoid squashing paintings or stretching character art.
6. Export all three editions from the same drawing records. InDesign layer order, bottom to top: generated page backgrounds; worksheet shapes/rules; supplementary art; editable type. Canva slides should preserve that same order and the exact font map. Native background resolution is distinct from a 300dpi PDF rasterization; disclose the former when describing print quality.
7. Render every final page and check background/text intersections, content omissions, teacher answer order, Korean font coverage, crop edges and illustration consistency. Fix the actual defect instead of shrinking everything. Deliver full-page designs, 4×4 sheet and 16 elements, prompt set, editable source and final PDFs together.

Keep supplied books, chapter text, generated character artwork and proprietary design references outside the public skill repository unless the user separately requests those materials to be published. Publish only reusable instructions and tooling under the skill's existing authorization.
